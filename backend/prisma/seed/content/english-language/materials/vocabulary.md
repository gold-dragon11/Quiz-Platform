## Слова, які легко сплутати

Це найчастіший тип завдань на лексику.

| Пара | Різниця |
| --- | --- |
| **say / tell** | *say* без адресата (*say something*), *tell* з адресатом (*tell somebody*) |
| **make / do** | *make* — створювати (*make a cake*), *do* — виконувати (*do homework*) |
| **borrow / lend** | *borrow* — брати в позику, *lend* — давати в позику |
| **bring / take** | *bring* — приносити сюди, *take* — забирати звідси |
| **travel / trip / journey** | *travel* — процес (незлічуване), *trip* — коротка поїздка, *journey* — довга подорож |
| **job / work** | *job* — конкретна посада (злічуване), *work* — робота загалом (незлічуване) |
| **listen / hear** | *listen* — слухати навмисне, *hear* — чути |
| **look / see / watch** | *look at* — дивитися, *see* — бачити, *watch* — спостерігати |
| **remember / remind** | *remember* — пам'ятати, *remind* — нагадувати комусь |
| **lose / miss** | *lose* — загубити, *miss* — сумувати; пропустити |
| **learn / study** | *learn* — вивчити (результат), *study* — вчитися (процес) |
| **fun / funny** | *fun* — приємно, *funny* — смішно |
| **economic / economical** | економічний / ощадливий |
| **historic / historical** | історично важливий / пов'язаний з історією |
| **sensible / sensitive** | розсудливий / чутливий |
| **affect / effect** | впливати (дієслово) / вплив (іменник) |

## Make чи do

**make** — creating: *make a decision, make a mistake, make progress, make friends, make money, make noise, make an effort, make a choice*.

**do** — performing: *do homework, do the shopping, do the washing-up, do business, do research, do a favour, do your best, do harm*.

## Синоніми з відтінками

Точність важлива: не всякий синонім підійде в будь-якому контексті.

- *big / large / huge / enormous* — за зростанням розміру;
- *small / little / tiny* — *little* часто емоційне;
- *say / speak / talk / tell* — *speak* про мову й формально, *talk* про розмову;
- *beautiful / pretty / handsome / good-looking* — *handsome* традиційно про чоловіків;
- *quick / fast / rapid* — *fast* про рух, *rapid* про зміни.

## Антоніми

Часто утворюються префіксами: *possible / impossible*, *agree / disagree*, *legal / illegal*, *patient / impatient*.

Але багато пар — окремі слова: *buy / sell*, *borrow / lend*, *arrive / leave*, *remember / forget*, *increase / decrease*.

## Тематичні групи

**Education:** subject, degree, undergraduate, tuition, curriculum, assignment, take an exam, pass / fail an exam, get a scholarship.

**Work:** apply for a job, CV, interview, promotion, salary, colleague, employer, employee, be made redundant, work overtime.

**Technology:** device, download, upload, browser, update, password, screen, charge, back up, log in.

**Health:** symptom, treatment, prescription, recover, injury, painkiller, keep fit, go on a diet.

**Environment:** pollution, recycling, waste, climate change, renewable energy, endangered species.

**Travel:** accommodation, luggage, boarding pass, delay, book a ticket, check in, sightseeing.

## Слова з різним значенням у контексті

Багато поширених слів багатозначні: *book* (книжка / замовляти), *run* (бігти / керувати), *fine* (добре / штраф), *right* (правильний / правий / право), *matter* (справа / мати значення).

## Як учити лексику

- Учіть слова **сполуками**, а не поодинці: *make a decision*, а не просто *decision*.
- Записуйте приклад речення — так запам'ятовується вживання.
- Повторюйте з інтервалами, а не все за раз.
- Групуйте за темами, а не за алфавітом.

## Типові помилки

- **say / tell** плутають: «He said me».
- **make / do** обирають навмання: «make homework».
- **borrow / lend** міняють місцями.
- **Дослівний переклад сполук:** «I have 15 years» замість *I am 15*.
- **Незлічувані іменники в множині:** «informations», «advices», «news are».
