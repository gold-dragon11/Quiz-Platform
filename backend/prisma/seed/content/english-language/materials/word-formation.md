## Навіщо це потрібно

У завданнях **word formation** дають корінь у дужках, а треба поставити слово в правильній формі:

*He showed great (BRAVE) → **bravery**.*
*It was a (SUCCESS) project → **successful**.*

Треба визначити, **яка частина мови** потрібна за структурою речення, і додати відповідний афікс.

## Суфікси іменників

| Суфікс | Приклади |
| --- | --- |
| **-tion / -sion** | information, decision, education |
| **-ment** | development, government, agreement |
| **-ness** | happiness, darkness, kindness |
| **-ity** | ability, activity, possibility |
| **-ance / -ence** | performance, difference, importance |
| **-ship** | friendship, relationship, membership |
| **-hood** | childhood, neighbourhood |
| **-er / -or / -ist / -ian** | teacher, actor, scientist, musician (особа) |
| **-th** | strength, growth, warmth |
| **-y** | difficulty, discovery, bravery |

## Суфікси прикметників

| Суфікс | Приклади |
| --- | --- |
| **-ful** | useful, careful, beautiful |
| **-less** | useless, careless, homeless |
| **-able / -ible** | comfortable, possible, reliable |
| **-ous** | dangerous, famous, curious |
| **-ive** | active, creative, expensive |
| **-al** | national, personal, musical |
| **-ic** | scientific, historic, energetic |
| **-y** | rainy, sunny, healthy |
| **-ent / -ant** | different, important, confident |

Пара **-ful / -less** — антонімічна: *useful* / *useless*, *careful* / *careless*.

## Суфікси дієслів і прислівників

**Дієслова:** *-ise / -ize* (modernise), *-en* (widen, strengthen), *-ify* (simplify, clarify).

**Прислівники:** **-ly** (quickly, carefully). Правопис: *happy → happily*, *true → truly*, *terrible → terribly*.

## Негативні префікси

| Префікс | Приклади |
| --- | --- |
| **un-** | unhappy, unable, unusual, unfair |
| **in-** | incorrect, invisible, independent |
| **im-** | impossible, impatient, impolite (перед *m, p*) |
| **il-** | illegal, illogical (перед *l*) |
| **ir-** | irregular, irresponsible (перед *r*) |
| **dis-** | disagree, dishonest, disappear |
| **mis-** | misunderstand, misuse (неправильно) |
| **non-** | non-smoker, non-stop |

Вибір **in- / im- / il- / ir-** залежить від першої букви кореня: перед *m, p* — **im-**, перед *l* — **il-**, перед *r* — **ir-**.

## Інші префікси

- **re-** — знову: *rewrite, rebuild*;
- **over-** — надміру: *overwork, overcook*;
- **under-** — недостатньо: *underestimate, undercooked*;
- **pre-** — до: *prehistoric, preview*;
- **co-** — спільно: *cooperate, coexist*;
- **inter-** — між: *international, interact*;
- **ex-** — колишній: *ex-president*;
- **self-** — сам: *self-confident*.

## Зміни в корені

Іноді корінь змінюється:

*long → length*, *strong → strength*, *wide → width*, *deep → depth*, *high → height*, *decide → decision*, *succeed → success*, *explain → explanation*, *pronounce → pronunciation*.

## Як виконувати завдання

1. Визначте, **яка частина мови** потрібна: після артикля чи прикметника — іменник; перед іменником — прикметник; після *be* — прикметник; біля дієслова — прислівник.
2. Перевірте, чи потрібне **заперечення** за змістом речення.
3. Перевірте **число** іменника й **правопис**.

*It is (POSSIBLE) to finish today, so we'll do it tomorrow.* — за змістом потрібне заперечення: ***impossible***.

## Типові помилки

- **Неправильний префікс:** «unpossible» замість *impossible*.
- **Забуте заперечення**, якого вимагає зміст.
- **Неправильна частина мови:** *success* замість *successful*.
- **Пропущена зміна кореня:** «longth» замість *length*.
- **Множина не поставлена**, коли її вимагає контекст.
