## Що це таке

**Фразове дієслово** — це дієслово з прийменником або прислівником, яке має **цілісне значення**, часто не пов'язане зі значеннями окремих слів.

*look* — дивитися, але *look **after*** — доглядати, *look **for*** — шукати, *look **up*** — шукати в довіднику.

Саме тому їх треба вчити цілими сполуками.

## Роздільні та нероздільні

**Separable (роздільні)** — додаток може стояти між частинами:

*Turn **off** the TV.* = *Turn the TV **off**.*

Але якщо додаток — **займенник**, він стоїть **обов'язково всередині**:

*Turn **it** off.* (не «turn off it»)

**Inseparable (нероздільні)** — частини не розділяють ніколи:

*Look **after** the children.* / *Look **after them**.* (не «look them after»)

До нероздільних належать *look after, look for, get on, run into, take after, come across*.

## Найуживаніші фразові дієслова

| Дієслово | Значення | Приклад |
| --- | --- | --- |
| **look up** | шукати в словнику | *Look up the word.* |
| **look after** | доглядати | *She looks after her grandmother.* |
| **look for** | шукати | *I'm looking for my keys.* |
| **look forward to** | з нетерпінням чекати | *I look forward to seeing you.* |
| **turn on / off** | вмикати / вимикати | *Turn off the TV.* |
| **turn up** | з'явитися; збільшити гучність | *He turned up late.* |
| **turn down** | відхилити; зменшити | *She turned down the offer.* |
| **give up** | кинути, здатися | *He gave up smoking.* |
| **put off** | відкласти | *They put off the meeting.* |
| **put on** | одягати | *Put on your coat.* |
| **take off** | знімати; злітати | *The plane took off.* |
| **take after** | бути схожим на родича | *She takes after her mother.* |
| **get up** | вставати | *I get up at seven.* |
| **get on with** | ладнати | *I get on well with my sister.* |
| **get over** | оговтатися | *He got over the illness.* |
| **find out** | дізнатися | *I found out the truth.* |
| **carry on** | продовжувати | *Carry on working.* |
| **run out of** | закінчитися (запас) | *We ran out of milk.* |
| **come across** | натрапити випадково | *I came across an old photo.* |
| **break down** | зламатися | *The car broke down.* |
| **bring up** | виховувати; порушити тему | *She brought up three children.* |
| **call off** | скасувати | *They called off the match.* |
| **set up** | заснувати | *He set up a company.* |

## Трислівні фразові дієслова

Мають дієслово + два прийменники й **завжди нероздільні**:

*look forward to, get on with, run out of, put up with, catch up with, come up with, get rid of, look down on*

*I can't **put up with** this noise.* (терпіти)
*She **came up with** a great idea.* (запропонувати)

## Багатозначність

Одне фразове дієслово може мати кілька значень — вирішує контекст:

- *take off* — знімати (одяг) / злітати (літак);
- *pick up* — підняти / забрати (когось) / навчитися мимохідь;
- *make up* — вигадати / помиритися / складати (частину);
- *turn up* — з'явитися / збільшити гучність.

## Стиль

Фразові дієслова типові для **розмовного** мовлення. У формальному письмі часто вживають однослівні відповідники:

| Розмовне | Формальне |
| --- | --- |
| find out | discover |
| put off | postpone |
| set up | establish |
| carry on | continue |
| give up | abandon, quit |
| look into | investigate |

## Типові помилки

- **Займенник після нероздільного дієслова:** «turn off it».
- **Розділення нероздільного:** «look the children after».
- **Пропущений другий прийменник:** «I look forward to see you» — потрібно *to seeing*.
- **Інфінітив після *look forward to*** — там герундій.
- **Дослівний переклад:** значення фразового дієслова не складається зі значень частин.
