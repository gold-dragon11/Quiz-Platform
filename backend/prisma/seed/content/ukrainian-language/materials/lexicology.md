## Лексичне значення

**Лексика** — словниковий склад мови. **Лексичне значення** — те, що слово означає.

Слова бувають **однозначні** (*береза*, *олівець*) і **багатозначні** (*голова* — частина тіла, керівник, передня частина колони).

**Пряме значення** — основне, первинне: *золотий перстень*. **Переносне** виникає за подібністю чи суміжністю: *золоті руки*, *золота осінь*.

Переносне значення — основа тропів: метафори, метонімії, епітета.

## Синоніми

**Синоніми** — різні за звучанням, але близькі за значенням слова: *говорити — казати — мовити — балакати*.

Ряд синонімів називають **синонімічним рядом**; його перше слово — **домінанта**, стилістично нейтральне.

Синоніми відрізняються:

- **відтінком значення:** *великий — величезний — колосальний*;
- **стилістичним забарвленням:** *обличчя* (нейтр.) — *лик* (висок.) — *пика* (зневажл.).

**Контекстуальні синоніми** зближуються за значенням лише в конкретному тексті.

## Антоніми

**Антоніми** — слова з протилежним значенням: *день — ніч*, *високий — низький*, *любити — ненавидіти*.

Антонімами можуть бути лише слова **однієї частини мови**. На антонімії будується **антитеза** — стилістична фігура протиставлення.

## Омоніми

**Омоніми** — однакові за звучанням і написанням, але цілком різні за значенням: *коса* (зачіска / знаряддя / мис), *ключ* (від дверей / джерело / зграя птахів).

Різновиди:

- **омофони** — однакове звучання, різне написання: *мене — мине*, *сонце — сон це*;
- **омографи** — однакове написання, різний наголос: *за́мок — замо́к*, *а́тлас — атла́с*;
- **омоформи** — збігаються лише в окремих формах: *три* (числівник) і *три* (наказовий спосіб від *терти*).

## Пароніми

**Пароніми** — слова, схожі за звучанням, але **різні за значенням**. Саме їх найчастіше плутають, і саме на них будують завдання НМТ.

| Пароніми | Значення |
| --- | --- |
| **адресат / адресант** | той, кому пишуть / той, хто пише |
| **військовий / воєнний** | пов'язаний з військом / пов'язаний з війною |
| **гривня / гривна** | валюта / прикраса на шию |
| **дипломат / дипломант** | фахівець із дипломатії / переможець конкурсу |
| **економний / економічний** | ощадливий / пов'язаний з економікою |
| **ефектний / ефективний** | вражаючий / результативний |
| **особистий / особовий** | приватний / стосується особи як одиниці обліку |
| **тактовний / тактичний** | делікатний / пов'язаний з тактикою |
| **чисельний / численний** | пов'язаний з числом / такий, якого багато |

## Походження лексики

**Питомі** українські слова — успадковані від праслов'янської або утворені в українській мові.

**Запозичення** приходять з інших мов. Ознаки: початкові *а, е, ф* (*актор*, *ефір*, *фабрика*); сполуки *кс, пс* (*текст*); незмінюваність (*кіно*, *таксі*, *метро*).

**Кальки** — буквальний переклад чужої моделі; часто це помилка: *приймати участь* (треба *брати участь*), *на протязі року* (треба *протягом року*).

## Лексика за вживанням

- **Загальновживана** — відома всім.
- **Діалектизми** — слова окремої місцевості: *ґазда*, *файний*, *легінь*.
- **Професіоналізми й терміни** — слова фаху: *афікс*, *синус*, *дебет*.
- **Історизми** — назви зниклих реалій, замінників не мають: *гетьман*, *кріпак*, *свитка*.
- **Архаїзми** — застарілі назви наявних речей, мають сучасні відповідники: *чоло* (лоб), *ланіти* (щоки), *уста* (губи).
- **Неологізми** — нові слова: *смартфон*, *блогер*, *застосунок*.

Різниця між історизмом і архаїзмом — у тому, чи існує сам предмет.

## Типові помилки

- **Пароніми вживають один замість одного:** *особовий* замість *особистий*.
- **Історизми плутають з архаїзмами.**
- **Синонімами вважають слова різних частин мови.**
- **Кальки з російської** сприймають за норму.
- **Омоніми плутають із багатозначними словами.** У багатозначного слова значення пов'язані, в омонімів — ні.
