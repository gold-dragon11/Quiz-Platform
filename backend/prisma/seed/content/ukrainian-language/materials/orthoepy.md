## Що вивчає орфоепія

**Орфоепія** — розділ мовознавства про правильну вимову звуків, звукосполук і наголошування слів. Дотримання орфоепічних норм — ознака культури мовлення.

## Вимова голосних

**Наголошені** голосні вимовляються чітко.

**Ненаголошені** зазнають змін:

- **[е]** наближається до [и]: *весна* вимовляється приблизно як [веисна];
- **[и]** наближається до [е]: *широкий* — приблизно [шиерокий];
- **[о]** перед складом з наголошеним [у] наближається до [у]: *зозуля* — приблизно [зоузулʹа].

Голосні **[а], [у], [і]** не змінюються ніколи — це важлива відмінність від російської мови, де ненаголошене [о] вимовляється як [а]. В українській *молоко* — це [молоко], а не [малако].

## Вимова приголосних

**Дзвінкі не оглушуються** в кінці слова та перед глухими: *хліб* [хлʹіб], *ніж* [нʹіж], *казка* [казка], *дуб* [дуб].

Виняток — префікс **з-** перед глухим може оглушуватися: *зшити* [шшити].

**Глухі перед дзвінкими одзвінчуються:** *боротьба* [бородʹба], *вокзал* [воґзал], *футбол* [фудбол].

**[в]** ніколи не переходить у [ф]: *вовк* [вовк], а в кінці складу звучить як нескладовий [ў]: *любов* [лʹубоў].

**[г] і [ґ]** — різні звуки: [г] гортанний (*гора*, *голова*), [ґ] проривний (*ґанок*, *ґудзик*, *аґрус*).

**Ч, ж, ш, дж** — завжди тверді: *чай*, *шість*, *жито*. Пом'якшена вимова — типова помилка.

**Щ** вимовляється як [шч]: *щастя* [шчастʹа].

## Наголошування

Українська мова має чимало слів, наголос у яких помиляються найчастіше. Ці слова треба просто вивчити.

| Правильно | Часта помилка |
| --- | --- |
| вимо́ва | ви́мова |
| виразни́й | вира́зний |
| нови́й | но́вий |
| фарту́х | фа́ртух |
| чорно́зем | чорнозе́м |
| одина́дцять | оди́надцять |
| чотирна́дцять | чотирнадця́ть |
| завда́ння | за́вдання |
| запита́ння | запи́тання |
| кіломе́тр | кіло́метр |
| ви́падок | випа́док |
| ре́шето | реше́то |
| до́нька | донька́ |
| ко́лесо | коле́со |
| подру́га | по́друга |
| середи́на | сере́дина |
| фено́мен | феноме́н |
| украї́нський | укра́їнський |

Наголос на **-надцять** у числівниках *одина́дцять*, *чотирна́дцять* падає на склад **-на-**.

Слова з **подвійним наголосом** (обидва варіанти нормативні): *за́вжди́*, *по́ми́лка*, *до́гові́р*, *про́сти́й*.

## Милозвучність

Українська мова уникає збігу приголосних і голосних. Для цього чергуються:

- **у / в:** *була в школі*, але *був у школі*;
- **і / й:** *брат і сестра*, але *Оля й Іван*;
- **з / із / зі:** *з мамою*, *із сином*, *зі школи*.

Правило просте: між приголосними — *у*, *і*, *із*; між голосними — *в*, *й*, *з*.

## Типові помилки

- **Ненаголошене [о] вимовляють як [а]** — вплив російської.
- **Оглушення дзвінких у кінці слова:** *[хлʹіп]* замість *[хлʹіб]*.
- **Пом'якшена вимова ч, ш, ж.**
- **[г] і [ґ] не розрізняють.**
- **Наголос за російським зразком:** *ново́* замість *нови́й*, *кіло́метр* замість *кіломе́тр*.
