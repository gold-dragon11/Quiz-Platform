## Лінійні рівняння

Рівняння виду $ax + b = 0$, де $a \ne 0$, має єдиний корінь $x = -\dfrac ba$.

Розв'язують у три кроки: розкрити дужки → перенести невідомі в один бік, числа в інший (зі зміною знака) → поділити на коефіцієнт.

**Приклад.** $5x - 2 = 3x + 8 \Rightarrow 5x - 3x = 8 + 2 \Rightarrow 2x = 10 \Rightarrow x = 5$.

Окремі випадки: якщо $a = 0$ і $b = 0$ — коренем є будь-яке число; якщо $a = 0$, а $b \ne 0$ — коренів немає.

## Квадратні рівняння

$$ax^2 + bx + c = 0, \qquad a \ne 0.$$

Кількість коренів визначає дискримінант $D = b^2 - 4ac$:

| $D$ | Корені |
| --- | --- |
| $D > 0$ | два: $x_{1,2} = \dfrac{-b \pm \sqrt D}{2a}$ |
| $D = 0$ | один: $x = -\dfrac{b}{2a}$ |
| $D < 0$ | дійсних коренів немає |

**Теорема Вієта** для зведеного рівняння $x^2 + px + q = 0$:
$$x_1 + x_2 = -p, \qquad x_1 \cdot x_2 = q.$$

Вона дає змогу підібрати корені усно: для $x^2 - 5x + 6 = 0$ шукаємо два числа з сумою $5$ і добутком $6$ — це $2$ і $3$.

**Неповні квадратні рівняння** розв'язують без дискримінанта:
- $x^2 = 49 \Rightarrow x = \pm 7$ (два корені, не один!);
- $x^2 + 5x = 0 \Rightarrow x(x + 5) = 0 \Rightarrow x = 0$ або $x = -5$.

**Добуток дорівнює нулю** тоді й лише тоді, коли нулю дорівнює один із множників: $(x - 1)(x + 4) = 0 \Rightarrow x = 1$ або $x = -4$.

## Дробові рівняння

Дріб дорівнює нулю, коли **чисельник дорівнює нулю, а знаменник — ні**.

**Приклад.** $\dfrac{x^2 - 1}{x - 1} = 0$. Чисельник: $x = \pm 1$. Знаменник забороняє $x = 1$. Відповідь: $x = -1$.

Загальна схема: знайти ОДЗ → звести до спільного знаменника → прирівняти чисельник до нуля → **відкинути корені, що не входять до ОДЗ**.

## Ірраціональні рівняння

Рівняння з невідомим під коренем. Обидві частини підносять до квадрата, але це може **додати сторонні корені**, тому перевірка обов'язкова.

**Приклад.** $\sqrt{x + 3} = x - 3$. Підносимо: $x + 3 = x^2 - 6x + 9$, звідси $x^2 - 7x + 6 = 0$, корені $1$ і $6$. Перевірка: при $x = 1$ права частина $-2 < 0$ — не підходить. Відповідь: $x = 6$.

Правило: корінь невід'ємний, тому й права частина має бути невід'ємною.

## Рівняння з модулем

$|f(x)| = a$ при $a > 0$ рівносильне сукупності $f(x) = a$ або $f(x) = -a$; при $a = 0$ дає $f(x) = 0$; при $a < 0$ коренів немає.

**Приклад.** $|x - 2| = 5 \Rightarrow x - 2 = 5$ або $x - 2 = -5 \Rightarrow x = 7$ або $x = -3$.

## Біквадратні рівняння

$ax^4 + bx^2 + c = 0$ розв'язують заміною $t = x^2$, де $t \ge 0$.

**Приклад.** $x^4 - 5x^2 + 4 = 0$. Заміна дає $t^2 - 5t + 4 = 0$, звідси $t = 1$ або $t = 4$. Повертаємось: $x = \pm1$, $x = \pm2$ — чотири корені.

Від'ємні значення $t$ відкидають одразу: $x^2$ не може бути від'ємним.

## Типові помилки

- **$x^2 = 49 \Rightarrow x = 7$.** Загублено другий корінь $-7$.
- **Немає перевірки в ірраціональному рівнянні.** Піднесення до квадрата — нерівносильне перетворення.
- **Не враховано ОДЗ у дробовому рівнянні.** Корінь, що обертає знаменник у нуль, треба відкинути.
- **Знак у теоремі Вієта.** Сума коренів дорівнює $-p$, а не $p$.
- **У біквадратному рівнянні забувають повернутися до $x$.** Знайдено $t$ — робота ще не завершена.
