## Первісна

**Первісною** для функції $f(x)$ називають таку функцію $F(x)$, похідна якої дорівнює $f(x)$:

$$F'(x) = f(x).$$

Це дія, обернена до диференціювання. Первісних нескінченно багато: якщо $F(x)$ — первісна, то й $F(x) + C$ — теж, бо похідна сталої дорівнює нулю.

**Невизначений інтеграл** — це множина всіх первісних:
$$\int f(x)\,dx = F(x) + C.$$

Стала $C$ обов'язкова у відповіді.

## Таблиця первісних

| $f(x)$ | $\int f(x)\,dx$ |
| --- | --- |
| $0$ | $C$ |
| $1$ | $x + C$ |
| $k$ | $kx + C$ |
| $x^n$, $n \ne -1$ | $\dfrac{x^{\,n+1}}{n+1} + C$ |
| $\dfrac1x$ | $\ln\lvert x \rvert + C$ |
| $e^x$ | $e^x + C$ |
| $\sin x$ | $-\cos x + C$ |
| $\cos x$ | $\sin x + C$ |

**Приклади.** $\int x\,dx = \dfrac{x^2}{2} + C$; $\int x^2\,dx = \dfrac{x^3}{3} + C$; $\int 2x\,dx = x^2 + C$; $\int 3\,dx = 3x + C$.

Первісна для $\sin x$ — саме $-\cos x$ (мінус з'являється, бо $(-\cos x)' = \sin x$).

## Властивості

$$\int \big(f(x) \pm g(x)\big)dx = \int f(x)\,dx \pm \int g(x)\,dx, \qquad \int k f(x)\,dx = k\int f(x)\,dx.$$

Сталий множник виносять за знак інтеграла; добуток і частку так розбивати **не можна**.

## Формула Ньютона — Лейбніца

Визначений інтеграл обчислюють так:

$$\int_a^b f(x)\,dx = F(b) - F(a),$$

де $F$ — будь-яка первісна. Стала $C$ тут скорочується, тому її не пишуть.

**Приклад.** $\int_0^2 x\,dx = \left.\dfrac{x^2}{2}\right|_0^2 = 2 - 0 = 2$.

**Приклад.** $\int_0^\pi \sin x\,dx = (-\cos \pi) - (-\cos 0) = 1 + 1 = 2$.

Порядок віднімання важливий: спершу верхня межа, потім нижня.

## Площа криволінійної трапеції

Якщо $f(x) \ge 0$ на $[a;\,b]$, то площа фігури між графіком і віссю $Ox$ дорівнює

$$S = \int_a^b f(x)\,dx.$$

**Приклад.** Площа під $y = x^2$ на $[0;\,3]$: $\int_0^3 x^2 dx = \dfrac{27}{3} = 9$.

**Площа між двома графіками** ($f$ вище за $g$):
$$S = \int_a^b \big(f(x) - g(x)\big)dx.$$

Межі інтегрування — абсциси точок перетину графіків.

Якщо функція від'ємна на проміжку, інтеграл дає від'ємне число; площа дорівнює його модулю.

## Об'єм тіла обертання

При обертанні криволінійної трапеції навколо осі $Ox$:

$$V = \pi \int_a^b f^2(x)\,dx.$$

**Приклад.** Для $y = x$ на $[0;\,1]$: $V = \pi\int_0^1 x^2 dx = \dfrac{\pi}{3}$.

## Типові помилки

- **Забуто $+C$** у невизначеному інтегралі.
- **$\int \sin x\,dx = \cos x$.** Правильно $-\cos x$; знаки в інтегруванні протилежні до тих, що в диференціюванні.
- **Формула $\dfrac{x^{n+1}}{n+1}$ при $n = -1$.** Тоді знаменник нульовий; для $\dfrac1x$ первісна — $\ln|x|$.
- **Межі підставлено навпаки.** Це змінює знак результату.
- **Від'ємний інтеграл видають за площу.** Площа не буває від'ємною.
