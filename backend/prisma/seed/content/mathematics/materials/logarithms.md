## Означення

**Логарифм** числа $b$ за основою $a$ — це показник степеня, до якого треба піднести $a$, щоб дістати $b$:

$$\log_a b = c \iff a^c = b, \qquad a > 0,\ a \ne 1,\ b > 0.$$

Простими словами: «у який степінь звести основу, щоб отримати число».

**Приклад.** $\log_2 8 = 3$, бо $2^3 = 8$. $\log_3 9 = 2$, бо $3^2 = 9$.

Умова $b > 0$ принципова: **логарифм від'ємного числа й нуля не існує**.

Позначення: $\lg b = \log_{10} b$ (десятковий), $\ln b = \log_e b$ (натуральний, $e \approx 2{,}718$).

## Основні рівності

$$\log_a 1 = 0, \qquad \log_a a = 1, \qquad a^{\log_a b} = b.$$

Остання називається **основною логарифмічною тотожністю**: $2^{\log_2 5} = 5$.

## Властивості

$$\log_a(xy) = \log_a x + \log_a y$$
$$\log_a \frac xy = \log_a x - \log_a y$$
$$\log_a x^{\,n} = n \log_a x$$
$$\log_{a^n} x = \frac1n \log_a x$$

**Перехід до нової основи:**
$$\log_a b = \frac{\log_c b}{\log_c a}, \qquad \text{зокрема } \log_a b = \frac{1}{\log_b a}.$$

**Приклад.** $\log_2 6 - \log_2 3 = \log_2 2 = 1$.

**Приклад.** $3^{2\log_3 4} = 3^{\log_3 16} = 16$.

## Логарифмічна функція

$y = \log_a x$ — функція, обернена до показникової.

- **Область визначення:** $x > 0$ — графік лежить лише праворуч від осі $Oy$.
- **Область значень:** усі дійсні числа.
- Графік проходить через $(1;\,0)$, бо $\log_a 1 = 0$.
- При $a > 1$ функція зростає, при $0 < a < 1$ — спадає.
- Вісь $Oy$ — вертикальна асимптота.

## Логарифмічні рівняння

**Метод зрівнювання:** $\log_a f(x) = \log_a g(x) \Rightarrow f(x) = g(x)$, з обов'язковою перевіркою ОДЗ.

**Метод означення:** $\log_a f(x) = c \Rightarrow f(x) = a^c$.

**Приклад.** $\log_3 x = 2 \Rightarrow x = 3^2 = 9$.

**Приклад.** $\log_2(x - 1) = 3 \Rightarrow x - 1 = 8 \Rightarrow x = 9$. ОДЗ ($x > 1$) виконано.

**ОДЗ шукають до розв'язування** — і саме вона відсіює сторонні корені.

**Приклад.** $\log_2 x + \log_2(x - 2) = 3$. ОДЗ: $x > 2$. Згортаємо: $\log_2 x(x-2) = 3 \Rightarrow x^2 - 2x - 8 = 0$, корені $4$ і $-2$. Другий не входить в ОДЗ. Відповідь: $x = 4$.

**Заміна.** У рівнянні $\log_2^2 x - 3\log_2 x + 2 = 0$ підстановка $t = \log_2 x$ дає $t^2 - 3t + 2 = 0$, звідси $t = 1$ або $t = 2$, тобто $x = 2$ або $x = 4$.

## Логарифмічні нерівності

Як і в показникових, знак залежить від основи:

- при $a > 1$: $\log_a f(x) > \log_a g(x) \iff f(x) > g(x)$;
- при $0 < a < 1$ знак змінюється на протилежний.

І завжди додається умова додатності обох виразів.

**Приклад.** $\log_2 x > 3 \Rightarrow x > 8$ (з урахуванням $x > 0$).

## Типові помилки

- **$\log_a(x + y) = \log_a x + \log_a y$.** Такої формули немає: сума логарифмів дорівнює логарифму **добутку**.
- **Не перевірено ОДЗ.** Корінь, що робить вираз під логарифмом недодатним, — сторонній.
- **Логарифм від'ємного числа.** Не існує, скільки б не хотілося.
- **Знак нерівності при основі, меншій за одиницю.**
- **$\log_2^2 x$ плутають із $\log_2 x^2$.** Перше — квадрат логарифма, друге — логарифм квадрата, що дорівнює $2\log_2|x|$.
