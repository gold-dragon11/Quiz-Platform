## Означення

**Вектор** — напрямлений відрізок. Його задають координатами: якщо початок у точці $A(x_1;\,y_1)$, а кінець у $B(x_2;\,y_2)$, то

$$\vec{AB} = (x_2 - x_1;\ y_2 - y_1).$$

Порядок віднімання: **з координат кінця віднімають координати початку**.

**Приклад.** Для $A(1;\,2)$ і $B(4;\,6)$: $\vec{AB} = (3;\,4)$. Вектор $\vec{BA}$ — протилежний: $(-3;\,-4)$.

## Довжина вектора

$$|\vec a| = \sqrt{x^2 + y^2}.$$

**Приклад.** $\vec a(3;\,4)$: $|\vec a| = \sqrt{9 + 16} = 5$.

Довжина ніколи не від'ємна; вона дорівнює нулю лише для нульового вектора $\vec 0 = (0;\,0)$.

## Дії з векторами

**Додавання і віднімання** — покоординатно:

$$\vec a + \vec b = (x_1 + x_2;\ y_1 + y_2), \qquad \vec a - \vec b = (x_1 - x_2;\ y_1 - y_2).$$

**Множення на число:**
$$k\vec a = (kx;\ ky).$$

При $k > 0$ напрям зберігається, при $k < 0$ — змінюється на протилежний, а довжина множиться на $|k|$.

**Приклади.** $\vec a(1;\,2) + \vec b(3;\,4) = (4;\,6)$; $\vec a(5;\,7) - \vec b(2;\,3) = (3;\,4)$; для $\vec a(1;\,3)$ маємо $2\vec a = (2;\,6)$.

**Приклад складніший.** Знайти $3\vec a - 2\vec b$, якщо $\vec a(1;\,2)$, $\vec b(2;\,1)$: $3\vec a = (3;\,6)$, $2\vec b = (4;\,2)$, різниця — $(-1;\,4)$.

Геометрично додавання — це правило трикутника (кінець першого вектора з початком другого) або паралелограма.

## Скалярний добуток

$$\vec a \cdot \vec b = x_1 x_2 + y_1 y_2 \qquad \text{або} \qquad \vec a \cdot \vec b = |\vec a| \cdot |\vec b| \cdot \cos\varphi.$$

Результат — **число**, а не вектор.

Звідси кут між векторами:
$$\cos\varphi = \frac{x_1x_2 + y_1y_2}{|\vec a| \cdot |\vec b|}.$$

**Приклад.** $\vec a(1;\,2)$, $\vec b(3;\,4)$: скалярний добуток дорівнює $3 + 8 = 11$.

## Колінеарність і перпендикулярність

**Колінеарні** (паралельні) вектори мають пропорційні координати:
$$\frac{x_1}{x_2} = \frac{y_1}{y_2}, \qquad \text{рівносильно } x_1y_2 - x_2y_1 = 0.$$

**Приклад.** При якому $x$ вектори $\vec a(x;\,6)$ і $\vec b(2;\,4)$ колінеарні? З пропорції $\dfrac x2 = \dfrac64$ дістаємо $x = 3$.

**Перпендикулярні** вектори мають нульовий скалярний добуток:
$$\vec a \perp \vec b \iff x_1x_2 + y_1y_2 = 0.$$

**Приклад.** $\vec a(2;\,3)$ і $\vec b(3;\,-2)$: $6 - 6 = 0$, отже вектори перпендикулярні.

Два критерії легко переплутати: **колінеарність — через пропорцію, перпендикулярність — через скалярний добуток**.

## Рівність векторів

Вектори рівні, якщо рівні їхні відповідні координати. Точка прикладання значення не має: вектор можна вільно переносити.

## Типові помилки

- **Координати вектора рахують від початку до кінця у зворотному порядку.** Це дає протилежний вектор.
- **Скалярний добуток вважають вектором.** Це число.
- **Умови колінеарності та перпендикулярності переставляють місцями.**
- **Довжину рахують як суму координат** замість $\sqrt{x^2+y^2}$.
- **Множення на від'ємне число не змінює напрям.** Змінює.
